# NAVARRO TRADE / Sterling Strategy Session v6.9

Раздел «Направления» — точка входа в подтверждённые пользовательским описанием процессы. Международный транзит (17 этапов), оптовая торговля внутри РК (6 этапов) и авиа-ГСМ с заправкой в крыло (7 этапов) открываются кликом по направлению.

Отдельный слайд «Бизнес-процессы» удалён. Всего девять экранов.

Карточки управленческих инициатив раскрывают схему внедрения, участников, контрольные точки, KPI и материалы-основания. Политика PPM из присланных источников рассматривается как образец сторонней компании, а не действующий документ Sterling.

В v6.1 все модальные окна используют почти всю площадь экрана. Разреженные этапы бизнес-процесса растягивают поясняющие блоки по высоте, а плотные кейсы сохраняют прокрутку. Типографика и карточки увеличены для проектора.

В v6.2 слайды 05–08 раскрывают детали в анимированной правой колонке без вызова модального окна. На слайде 03 клик по оргблоку лишь обновляет превью; модальный разбор открывается только по кнопке. На слайде 04 вспомогательный блок убран, а полный разбор кейса открывается непосредственно по клику на карточку.

В v6.3 текст раскрытых колонок распределяется по сбалансированному потоку без растянутых пустых карточек; кегль и интервалы адаптируются к высоте экрана.

В v6.4 направление «Авиа-ГСМ и заправка в крыло» раскрывается как семиэтапный процесс с проблемным кейсом заявок вне рабочего времени и цифровым решением. Со слайда стратегического роста убраны ION ENERGY и мобильный ТЗК. Фирменный логотип NAVARRO TRADE добавлен на обложку и в постоянную навигацию.

В v6.5 раскрываемые колонки слайдов 05–08 перераспределяются в три сбалансированных столбца на презентационных экранах. Формулировки инициатив и роста сокращены без потери смысла; внутреннее переполнение устранено при разрешении 1280×720.

В v6.6 кегль основного текста раскрытых колонок увеличен до 14,5–15 px, заголовков карточек — до 15 px, а вторичного текста — до 12,5 px. Компоновка обзорных слайдов уплотнена без внутренней прокрутки, чтобы презентация читалась с большого экрана при 1280×720.

В v6.7 из пользовательского интерфейса убраны служебные пояснения о навигации, модальных окнах, раскрытии карточек и изменениях структуры презентации. Подзаголовки теперь описывают только бизнес-содержание слайдов.

В v6.8 кейс о перекрывающихся функциях изложен обобщённо, без названий конкретных компаний и подразделений.

В v6.9 терминология международного транзита уточнена: поставки с КНР, SGS и произведение пропарки вагонов; в приёмке указан Almaty Sterling Terminal. В оптовой торговле «НПЗ» заменён на «поставщик».

В той же редакции v6.9 должность COO удалена из проектной оргструктуры. Транспортная логистика, транзитные операции, PCQA и AFO перенесены в коммерческий департамент; связанные формулировки ответственности обновлены во всей презентации.

## Обновление на GitHub Pages

Для **проверки параллельно** с действующей презентацией распакуйте ZIP в корень репозитория и выполните:

```bash
node session-v6/validate.js
git add session-v6/
git commit -m "Add Sterling strategy session v6 detailed briefings"
git push origin main
```

Адрес: `https://armashkiss.github.io/NavarroTradeOverview/session-v6/`

Для замены `/session/` после согласования скопируйте содержимое `session-v6/` в `session/`.
