# NAVARRO TRADE / Sterling Strategy Session v6.1

Раздел «Направления» — точка входа в подтверждённые пользовательским описанием процессы. Международный транзит (17 этапов) и оптовая торговля внутри РК (6 этапов) открываются кликом по направлению. Авиа-ГСМ раскрывает обзор деятельности без выдуманного технологического маршрута.

Отдельный слайд «Бизнес-процессы» удалён. Всего девять экранов.

Карточки управленческих инициатив раскрывают схему внедрения, участников, контрольные точки, KPI и материалы-основания. Политика PPM из присланных источников рассматривается как образец сторонней компании, а не действующий документ Sterling.

В v6.1 все модальные окна используют почти всю площадь экрана. Разреженные этапы бизнес-процесса растягивают поясняющие блоки по высоте, а плотные кейсы сохраняют прокрутку. Типографика и карточки увеличены для проектора.

## Обновление на GitHub Pages

Для **проверки параллельно** с действующей презентацией распакуйте ZIP в корень репозитория и выполните:

```bash
node session-v6/validate.js
git add session-v6/
git commit -m "Add Sterling strategy session v6 detailed briefings"
git push origin main
```

Адрес: `https://armashkiss.github.io/NavarroTradeOverview/session-v6/`

Для замены `/session/` после согласования скопируйте содержимое `session-v6/` в `session/`.
