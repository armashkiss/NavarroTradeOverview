# Sterling Strategy Session — NAVARRO TRADE v4.3

Полная интерактивная версия с кейсами и цифрами из переданных подразделениями материалов. **ВНИМАНИЕ: содержит внутренние сведения Sterling Group. При публикации в GitHub Pages их сможет увидеть любой посетитель сайта, а также останется Git-история.**

## Возможности

- CEO → руководство → департаменты → отделы: нажатия раскрывают ветки без перезагрузки слайда. Выбранная структура визуально фокусируется; справа появляются подробные функции.
- Три модели сделок: оптовый авиакеросин, заправка в крыло, транзит — подробные этапы с кейсами, документами и предложениями.
- 8 случаев из материалов: количественные расхождения, оснащение базы, взаиморасчёты, закупки и договорные процессы.
- Плавные переходы между этапами, разделами и панелью деталей; режим показа на весь экран.
- Кликер: ArrowRight / PageDown / Space — вперёд; ArrowLeft / PageUp — назад; Home / End — начало и конец; F — на весь экран; Esc — выйти.
- Решения можно отмечать и выгружать как черновик Markdown. Отметки **не являются официальным протоколом**.

## v4.2 · Проекционный режим кейсов
Нажмите на карточку: её разбор раскроется почти на весь экран с колонками, без пересечения с нижней навигацией. Esc или кнопка «К схеме» закрывают крупный план. На узких мобильных экранах длинные материалы прокручиваются, чтобы не обрезать текст.

## v4.3 · Executive insight

Окно разбора переработано в компактный executive-board: отдельная контекстная полоса, усиленная иерархия, визуально разделённые смысловые блоки и адаптивная компоновка. При открытии фокус переходит внутрь диалога, Tab остаётся в его пределах, а после закрытия возвращается к выбранной карточке.
