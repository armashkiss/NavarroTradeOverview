# NAVARRO TRADE / Sterling Strategy Session — интерактивная презентация

Автономный презентационный веб-сайт (HTML/CSS/JS, без сервера и сборщика).

## Локальный запуск

В каталоге `site`:

```bash
python3 -m http.server 8080
```

Откройте `http://localhost:8080/` (можно открыть и `index.html` двойным щелчком).

## Управление

- Клик по разделам слева — смена слайда.
- Клик по карточкам — подробность справа.
- На оргструктуре виден CEO и прямые подчинённые; клик по ним раскрывает их отделы. Коммерческий департамент можно раскрыть ещё на уровень.
- Стрелки `← →` или кнопки снизу — смена слайда.
- На последнем слайде можно пометить решения и экспортировать рабочий Markdown-реестр.
- Состояние решений хранится только в localStorage вашего браузера.

## Что относится к проектам, а не утверждённым фактам

Все новые роли, исполнительные подразделения, RACI и предложения представлены как проект TO-BE. Факты из докладов подразделений не проверялись независимо. PPM-политика приложена как образец и **не утверждена Sterling**.

## Развёртывание рядом с текущим сайтом GitHub Pages

Рекомендуется разместить **публично безопасную** сборку в папке `session/` существующего репозитория; тогда действующий основной сайт не изменится:

`https://armashkiss.github.io/NavarroTradeOverview/session/`

Не размещайте внутреннюю сборку с суммами задолженности и операционными разборками на общедоступном Pages. Даже приватный GitHub-репозиторий не гарантирует закрытого доступа к Pages.
