# NAVARRO TRADE · session-v6 · layout patch 6.10

Исправляет переполнение подробных карточек в разделах «Компании холдинга», «Изменения и решения», «Точки роста» и «Решения сессии».

## Изменения
- Карточки раскрываются в широкое модальное окно; текущий слайд и исходные тексты не заменяются.
- Балансировка блоков по реальной высоте, переменное число колонок и плотность.
- Если содержимое не помещается, оно делится на последовательные страницы **без скролла**, доступные кнопками и кликером.
- Сохраняются Escape/закрытие, полноэкранный показ, анимация увеличения от выбранной карточки.

## Установка поверх свежего main

```bash
unzip -o ~/Загрузки/NAVARRO_Session_v6_10_Layout_Patch.zip -d /home/armashka/NAVARRO_TRADE_GitHub_Pages_Ready
cd /home/armashka/NAVARRO_TRADE_GitHub_Pages_Ready
python3 tools/apply_session_v6_layout.py
node session-v6/validate.js
```

Скрипт меняет только `session-v6/index.html` и `session-v6/assets/app.js`, подключает новый `session-v6/assets/presentation-fit.css`. Патч идемпотентный. При изменённой структуре исходного JS он прекращает работу вместо попытки слепой замены.

## Тестирование
В изолированном Chromium на макете подробного кейса проведены проверки 1704×950, 1440×900, 1366×768, 1100×750, 1024×700, 860×520. На первых пяти всё помещается одним экраном; на последнем используется пагинация. Полный опубликованный сайт в этом окружении запустить не удалось, поэтому после установки проверь ключевые разделы на своём компьютере.
